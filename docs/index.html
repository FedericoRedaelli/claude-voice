Claude Code plugin

claude-voice
Claude answers. You answer back — out loud.

At every stopping point, Claude hands its final text to a voice agent that reads it aloud, takes your questions, and sends your decision back. You keep reading the terminal — the call is just about it.

Install GitHub

The loop

01

Claude writes

Full answer in the terminal as usual — results, paths, numbered options. Nothing is moved into the call.

02

A beep, then silence

The mic listens locally for 30 seconds. No audio leaves the machine, no API session, no cost — until you actually speak.

03

You talk back

Pick one of the options or say something else entirely. The agent reports the decision and Claude picks up from there.

Why it isn't annoying

  • Nothing starts talking on its own. Walk away mid-task and the loop just ends quietly — no voice narrating to an empty room. You pick it back up at the keyboard.
  • It won't interrupt itself. Half-duplex by default: the mic is muted while the agent talks, so laptop speakers can't echo it back. Use headphones for barge-in.
  • Esc kills the call. Instant silence — no closing beep, no draining. The tool returns end and Claude stops.
  • It never invents a choice. An option is only reported when you picked it whole. A mix, a condition, a different idea — those go back as your own words.

Install

# 1. deps
cd claude-voice && npm install

# 2. try the whole loop with zero external deps
VOICE_MODE=text claude --plugin-dir ./claude-voice

# 3. for real voice
export OPENAI_API_KEY=sk-...
claude --plugin-dir ./claude-voice

Inside Claude Code, confirm with /mcp — look for the voice server and its talk_to_user tool.

Config

VariableDefault
OPENAI_API_KEY—Required for voice mode.
VOICE_MODEvoicetext runs the same loop in the terminal.
VOICE_LANGEnglishWhat the agent speaks, whatever you speak.
VOICE_NAMEalloyPinned voice — otherwise it drifts between sessions.
VOICE_WAIT_MS30000How long it listens before ending without a session.
VOICE_HALF_DUPLEX10 enables barge-in — headphones only.

Twenty more knobs — VAD thresholds, noise reduction, timeouts, the Stop-hook switch — in the full table on GitHub. Persist any of them in a gitignored .env.

  • Node.js 22+
  • sox for mic and speaker (voice mode only)
  • An OpenAI API key with Realtime access (voice mode only)
